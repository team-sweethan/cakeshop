# 쿠폰 도메인 개요

쿠폰 도메인이 현재 제공하는 기능과 주요 흐름을 빠르게 확인하기 위한 안내 문서다.
상태 전이·수량 제약·수정 제한·도메인 간 계약처럼 구현 판단이 필요한 규칙의 정본은
[`coupon_conventions.md`](coupon_conventions.md)다. 두 문서가 다르면 `coupon_conventions.md`를 따른다.

## 현재 지원 범위

- 관리자: 쿠폰 등록, 목록·상세 조회, 수정, 발급 중지·재개
- 발급 대상: 전체 회원, 신규 회원, 첫 주문 회원, 생일 회원, 특정 회원
- 특정 회원: 상세 화면에서 후보를 검색하고 수동 발급·발급 취소
- 고객: 마이페이지에서 사용 가능한 보유 쿠폰 조회
- 주문·결제: 주문서 쿠폰 선택, 할인 미리보기, 예약, 사용 확정, 취소·만료 시 복구

## 핵심 흐름

```text
관리자 쿠폰 등록
  → 발급 대상 정책에 따라 자동 발급 또는 수동 발급 대기
  → 회원별 member_coupons 발급 이력 생성

생일 쿠폰 자동 발급
  → 매일 00:00(Asia/Seoul)에 해당 월 생일 회원을 조회
  → 조회 시점의 대상 회원에게만 발급 시도
  → 중복 이력·쿠폰 중지·만료는 발급 INSERT 시 다시 확인

고객 주문서
  → 사용 가능한 쿠폰 조회 및 할인 미리보기
  → 주문 생성 시 쿠폰 예약(RESERVED)
  → 결제 성공 시 사용 완료(USED)
  → 결제 실패·만료·주문 취소 시 사용 가능(AVAILABLE)으로 복구
```

## 범위 밖 또는 후속 기능

- 고객의 쿠폰 상세 조회·직접 발급 정책 확장
- 발급 실패 이력·재처리 운영 기능
- 부분 취소 시 쿠폰 복구 정책

후속 기능은 현재 구현으로 추정하지 않고, 추가 전 `coupon_conventions.md`의 보류·연동 정책을 확인해
담당 도메인과 합의한다.
