# 계약 제안 (임시)

여기 있는 문서는 **합의를 받기 위한 제안서**이고 정본이 아니다.

- 담당자 확인이 끝나면 **결론은 `docs/review/SPEC.md`(규칙과 근거)와 `docs/review/PLAN.md`(결정 로그 한 줄)로 옮기고 이 디렉터리는 지운다.**
- 그때까지만 SPEC과 나란히 존재한다. **어긋나면 SPEC이 맞다.**

제안서를 repo에 둔 것은 코드와 함께 봐야 판단이 되기 때문이다. 인터페이스만 떼어 놓고 보면 "왜 이 인자인지"가 안 보인다.
