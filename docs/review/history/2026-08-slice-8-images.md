# 조각 8 — 이미지 첨부 (2차, PR #313 머지 완료)

> **끝난 조각의 기록이다. 지금 구속하지 않는다.**
> 이 조각이 만든 규칙의 정본은 `../specs/review-write.md`.
> 조각 순서와 진행 상태는 `../PLAN.md`, 발견된 문제는 `../reviews/`,
> 방향을 고른 판단은 `../decisions/`에 있다.

기존 `review_images`와 공용 `FileStorageClient`를 사용한다. 작성 폼에서 선택한 순서대로 최대 3장을
후기 저장 트랜잭션 안에서 붙이고, 상품 후기 미리보기·전체 목록, 내 후기, 관리자 상세에 노출한다.
장당 5MB 이하의 JPEG·PNG만 받으며 확장자·MIME·시그니처가 모두 일치해야 한다. 파일은 먼저 전부
검증하고, 트랜잭션이 롤백되면 이미 저장한 파일을 정리한다. 수정 화면의 이미지 추가·삭제는 A6의
경로(A2·A3)에 포함되지 않으므로 열지 않았고, 후기 숨김·soft delete 때도 행과 파일을 유지한다.
**이때 수정 화면이 첨부 이미지를 그리지도 않아** 작성자에게는 사라진 것으로 보였다. 08-20에 읽기
전용 표시만 더했다(편집은 여전히 닫혀 있다).

**검증**: 3장 경계와 4장 거부, 형식·용량 검증, 한 장이 잘못되면 아무 파일도 저장하지 않는지,
rollback 파일 정리, DB 표시 순서, 고객 세 화면과 관리자 상세 렌더링.
