해석 포인트

  1. "앞선 커밋" = 해당 브랜치에는 있지만 dev에는 아직 없는 커밋 수.
  2. "뒤처진 커밋" = dev에는 있지만 해당 브랜치에는 없는 커밋 수.
  3. "앞선 커밋"이 0이면 그 브랜치의 모든 커밋이 이미 dev에 들어갔다는 뜻이다.
  4. main은 릴리스 브랜치라 앞선 커밋이 0인 것이 정상이다. main의 "뒤처진 커밋"은 아직 릴리스되지 않은 dev의 작업량이다.
이 페이지는 .github/scripts/branch-status.sh 가 매일 00시(KST)에 다시 만든다. 손으로 고쳐도 다음 실행 때 사라진다.
위 수치는 기준 커밋 7a733df 시점의 스냅샷이다. 정확한 값은 git rev-list --left-right --count origin/dev...origin/<브랜치> 로 확인한다.
